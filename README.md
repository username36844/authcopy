# Should You Use Labels?

Yes.
But:

# visually subtle labels.

Do NOT rely on placeholders alone.

---

# Why Placeholders-Only Is Weak

Because once the user types:

* context disappears
* accessibility drops
* scanning becomes worse
* forms feel less stable

Premium SaaS products usually use:

# persistent labels + placeholders.

But labels should feel:

* lightweight
* quiet
* integrated

NOT:

```txt id="ybjlwm"
BIG FORM LABELS
```

---

# Recommended Pattern

## Label

Small muted label above input:

```txt id="jlwm1a"
Work email
```

---

## Placeholder

```txt id="jlwm2b"
you@studio.com
```

This is the ideal balance.

---

# Your Labels Should Be:

| Property      | Direction  |
| ------------- | ---------- |
| Font size     | 13px–14px  |
| Weight        | medium     |
| Color         | slate-500  |
| Margin bottom | very tight |
| Tone          | quiet      |

---

# Final Verdict

## YES:

Use labels.

But:

# make them subtle and structural.

Not visually dominant.
